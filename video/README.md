# Студия TikTok-роликов

Каждый ролик — отдельная папка в `projects/`. Движок (Remotion, Node) общий, ставится один раз.

## Новый ролик за 3 шага
1. **Создай проект:** двойной клик по **`Новое видео.bat`** → введи название. Откроется папка `inbox/` нового проекта.
   (Или в терминале из `video/`: `npm run new -- "Мой ролик"`.)
2. **Закинь материалы** в `inbox/` как есть: видео, музыку, 3D-модели, картинки, шрифты. Ничего переименовывать не нужно.
3. **Напиши бриф:** заполни `brief.md` в папке проекта или просто опиши ролик в чате. Затем скажи Claude:
   «сделай ролик <имя-папки>». Claude уточнит детали, предложит план, соберёт ролик и пришлёт результат.

Готовое видео: `projects/<имя>/out/<имя>.mp4`.

## Что где лежит в проекте
| Папка / файл | Что это |
|---|---|
| `brief.md` | бриф: о чём ролик, хук, длительность, музыка, стиль |
| `inbox/` | твои исходники (Claude их не меняет) |
| `NOTES.md` | статус и решения, ведёт Claude |
| `src/` | код монтажа (Remotion) |
| `public/`, `work/` | подготовленные ассеты и промежуточные файлы |
| `out/` | готовые ролики |

В git (и на GitHub) попадают только бриф, заметки и код. Материалы и рендеры остаются на этом ПК.

## Команды (из папки `video/`)
- `npm run list` — все ролики и их статус
- `npm run studio -- <имя>` — превью в браузере
- `npm run render -- <имя>` — собрать ролик
- `npm run build -- <имя>` — полная сборка, если у ролика есть свой пайплайн (например, 3D в Blender у `kayn-edit`)

Важно: сессии Claude открывай в корне репозитория `D:\git\aigoogle` — там лежат все скиллы (`.claude/skills`).

## Один раз на новом ПК
Нужны Node.js, ffmpeg, Git for Windows; для 3D — Blender, для анализа музыки — Python с librosa.
Затем в `video/`: `npm install`.
