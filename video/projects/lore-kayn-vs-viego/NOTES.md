### Озвучка (облако: веб-TTS через websocket заблокирован прокси → только локально)
- `pip install --break-system-packages piper-tts` (может идти 2–4 мин, ставь timeout 300000).
- Голос: `ru_RU-denis-medium` (проверен в облаке 09.11): скачать `.onnx` и `.onnx.json` с
  `https://huggingface.co/rhasspy/piper-voices/resolve/main/ru/ru_RU/denis/medium/` в `work/voices/`.
  Запасные: `ru_RU/dmitri/medium`, `ru_RU/ruslan/medium` — сделай по 1 фразе каждым и выбери самый «рассказчиковый».
- Синтез по сценам: `echo "<текст>" | python3 -m piper -m <voice>.onnx -f work/vo/NN.wav --length-scale 1.12
  --sentence-silence 0.25`. Стиль: спокойный, низкий, с паузами (как у лор-рассказчиков) — не клонировать чужой голос.
- Обработка: ffmpeg `highpass=f=70, lowshelf +3 dB @150 Hz, acompressor, aecho=0.8:0.6:40:0.15` (лёгкий зал),
  `loudnorm=I=-16:TP=-1.5`. Склейка сцен с паузой 0,25 с → `out/voice.wav`.
- Длительность сцены = длина её озвучки + 0,25 с (мин. 2,5 с). Итог ≈ 60–70 с.

### Субтитры по словам
- Тайминги слов: whisper (`@remotion/install-whisper-cpp`, модель `small`, язык ru — скилл `remotion-captions`);
  если не ставится — распределить слова внутри фразы пропорционально числу символов (озвучка синтетическая, ровная).
- Вид (как в референсе): по 1–2 слова, по центру кадра (y ≈ 50 %), белый жирный 80–90 px, чёрная обводка 6 px,
  pop-in 4 кадра. Цвет ключевых слов: «Каин/Рааст/даркин» — #FF3B3B, «Виего/туман/король» — #2EF2A0.
- Безопасные зоны TikTok: верх 150 px, низ 420 px, справа 140 px.

### Картинка
- Remotion 1080×1920, 30 fps (статичный арт). Каждая PNG: cover-масштаб ×1.15 (lanczos, предварительно ffmpeg →
  `public/`), поверх — наезд/дрейф по таблице. Склейки — жёсткие в начале фразы; вспышки только где указано.
- Частицы: красные угли (сцены 2, 6–8), зелёный туман/искры (4, 5, 9, 11–15) — canvas/SVG в Remotion
  (скилл `particle-system`), полупрозрачные, не закрывают лица.
- Цвет: лёгкий контраст +6 %, насыщенность +5 %, без CSS filter на весь кадр — вшить в PNG через ffmpeg (`tools/grade.sh`).
- Проверка: стоп-кадры 0, 3, 15, 30, 45, 60 с и последний — субтитры читаются, лица не перекрыты.

## Решения v1 (отличия от задания и почему)
- Голос `ru_RU-ruslan-medium`, а не denis: самый низкий (медиана F0 ≈105 Гц против 139 у denis и 182 у dmitri),
  модель обучена на корпусе аудиокниг RUSLAN. Слушать в облаке нельзя, выбор сделан по высоте голоса и корпусу.
- `length-scale 1.0` вместо 1.12: при 1.12 вышло 83 с (цель 60–70). При 1.0 — 78,5 с, это естественный темп
  ruslan. Быстрее не делал, чтобы голос не звучал скороговоркой. Короче — `lengthScale` в `pipeline/scenes.json`.
- Тайминги слов не через Whisper: Piper 1.8 сам отдаёт выравнивание фонем (`include_alignments`, нужен пакет `onnx`).
  Тайминги точные, число слов сверяется с текстом. Whisper и его модели не нужны.
- Звук в mp4 подмешан ffmpeg после рендера (`--muted` + mux), потом перекодировано в yuv420p (Remotion даёт yuvj420p).
- Облако: huggingface.co закрыт в окружении Default → создано личное окружение «AIGOOGLE» с доступом к
  huggingface.co + `us.aws.cdn.hf.co` (CDN файлов моделей). PyPI в облаке медленный (~100 кБ/с).
- `remotion.config.ts`: headless shell в облаке теперь ищется автоматически (папка сменилась с 1194 на 1243).

## v2 — «живые картинки» вместо слайдшоу (отзыв пользователя 09.11: «нет движения в кадре, только слайдшоу»)
Причина: в v1 только наезд 1.0→1.1 за сцену + частицы поверх → читается как слайдшоу. Нужно движение ВНУТРИ картинки.
Голос, субтитры, тайминги (`src/timeline.json`) — оставить как есть, менять только картинку.

1. **Карты глубины** (`pipeline/depth.py`): `pip install --break-system-packages onnxruntime`; модель Depth Anything V2
   Small в ONNX с Hugging Face (`onnx-community/depth-anything-v2-small`, файл onnx/model.onnx) → для каждой PNG
   `public/depth/<img>.png` (16-бит или 8-бит, сглаженная, того же размера). Проверить 2–3 карты глазами.
2. **Шейдер «2.5D-картинка»** в Remotion (WebGL: `@remotion/three` или canvas WebGL; скиллы `shader-glsl`,
   `threejs-animation`), вместо `<Img>`:
   - параллакс: `uv += camOffset * (depth - 0.5) * 0.04` — камера плавно смещается вбок/по дуге, ближние планы
     двигаются сильнее дальних (эффект объёма);
   - «дыхание» переднего плана: где depth > 0.6 — масштаб 1.000↔1.006, период ~4 с;
   - **туман течёт**: маска = зелёные/сине-зелёные пиксели средней яркости (+ красная дымка в красных сценах) →
     `uv += flowNoise(uv*3 + t*0.15) * 0.006 * mask` (медленное течение, без рваных краёв);
   - **свечение живёт**: маска = очень яркие насыщенные пиксели (глаза, коса, корона, луна) → пульс яркости
     ±15 % с разной фазой + мягкий glow (размытая копия маски, add);
   - лёгкое мерцание углей/искр по той же маске в красных сценах.
3. **Камера сильнее**: зум 1.0→1.18–1.25 за сцену + боковой дрейф 2–4 % ширины (для параллакса); экшен-сцены
   (06, 07a, 07b, 13): быстрый наезд за 0,3–0,5 с + встряска + RGB-сдвиг 3 px 2–3 кадра на ударах.
4. **Переходы**: вместо жёстких склеек на 4–5 сценах — короткий «вайп туманом» (маска шума 8–10 кадров) или
   вспышка; на ударах 07b — разрез по диагонали (кадр съезжает половинками 6 кадров).
5. Проверка: по 1 контакт-листу (6 кадров) на сцену — движение должно быть видно между соседними кадрами
   (не только зум). Потом полный рендер → тот же `out/lore-kayn-vs-viego.mp4` (голос + субтитры внутри) → отправить.
