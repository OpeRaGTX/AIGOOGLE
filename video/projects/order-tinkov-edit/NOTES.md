# Заказ FunPay: эдит про Олега Тинькова — заметки производства

Статус: бриф (ждём от клиента интро, трек; от продавца — подборку фото/видео Тинькова)
Создан: 2026-11-13

## Как собрать (для Claude, когда материалы в inbox/)
1. ffprobe всех файлов; трек → `python tools/beats.py inbox/track.mp3` (ставит librosa при отсутствии: pip install
   --break-system-packages librosa) → доли; дроп = место, указанное клиентом, или первый сильный пик громкости.
2. Remotion 1080×1920 30 fps: интро до дропа (кроп cover), затем EDL «кадр на долю» (при 125 BPM ≈ 0,48 с), фото —
   лёгкий наезд 1.00→1.06 за кадр, видео — лучший 0,5-с кусок. На 3–4 сильных долях — зум-рывок 1.0→1.25 за 4 кадра
   + радиальный/моушн-блюр (2–3 кадра). Белая вспышка 1 кадр на дропе.
3. Стикер-текст на интро (белый, «готический» шрифт с Google Fonts, напр. UnifrakturCook) с ~4-й секунды.
4. Цветокор вшить (`tools/grade.sh`), звук: трек как есть, громкость −14 LUFS.
5. Рендер → `out/order-tinkov-edit.mp4`, контакт-лист для проверки, отправить пользователю (SendUserFile).
