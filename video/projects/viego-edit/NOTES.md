# Эдит Виего — заметки производства

Статус: финал
Создан: 2026-10-29 (облачная сессия)

## Решения
- 34,34 с, 1080×1920, 60 fps; трек 139,7 BPM: разгон 0–3,4 с, провал баса 3,4–4,97 с, дроп 4,97 с, аутро с 30,6 с.
- Киллы в геймплее (исходник 23,5 с): 5,75 / 7,45 / 11,7 / 15,65 / 20,25 (пента) — посажены на сильные доли
  5,648 / 7,35 / 11,82 / 15,935 / 20,637; слоумо 0,5× (пента 0,4×) вокруг каждого килла.
- 3D (Blender Cycles, 30 fps + моушн-блюр, в 60 fps дублированием кадров): V1 интро (Respawn, падение с неба,
  наезд к лицу на провале баса), V2 удар со спины → кран вверх, V3 орбита снизу со вспышками ауры, V4 пике сверху
  + удар, V5 боковой трекинг с ударом, V6 спиральный кран, V7 крупный план → отъезд под титр.
- Окружение: парящие каменные блоки с изумрудным контуром, туман-хейз, изумрудные частицы; шлейф по лезвию меча
  (кость `Sword_vfx`), блоки у траектории камеры удаляются (`prune_blocks`).
- Текст: только титр «VIEGO / THE RUINED KING» на аутро. Цветокор вшит в mp4 (`tools/grade.sh`).
- Цветокор шотов: grade 1.08/1.08/1.06 + gamma 1.28 (поднятые тени — тёмная сцена читается на телефоне).

## Материалы
- `work/in/`: `7e7e9469.glb` idle, `9133de31.glb` dance, `956c3d0a.glb` attack, `d7d22b75.glb` respawn,
  `16bb3970.glb` T-поза, `game.mp4` геймплей, `track.wav` (аудио из присланного видео).

## Как пересобрать
- 3D: `blender -b -P pipeline/b3d/vshots.py -- V1_intro 12 full work/renders`, затем `pipeline/shot2mp4.sh V1_intro`.
- Монтаж: `npm run render -- viego-edit`.
