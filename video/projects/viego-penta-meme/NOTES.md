## Удержание (аналитик)
- 0–1 с: результат и мем сразу — главный фильтр пройден. Риск: плашка читается >1 с → текст ≤7–8 слов, 2 строки.
- 1,3 с: перемотка = открытая петля («как?»), закрывается только на 7,3–9,5 с.
- Каждые 0,9–1,3 с новый килл + счётчик 1/5→5/5 — прогресс-бар, досматривают до 5/5.
- 6,9 с: 3D-вставка ломает паттерн геймплея → второй повторный хук.
- Финал = кадр 0 → пересмотры.

## Сборка (Remotion, `src/`)
1. ffmpeg: `inbox/game.mp4` → `public/game.mp4` (60 fps, как в viego-edit `work/gameplay` если есть); реверс-клип
   20,7→5,0 с, ускоренный до 0,43 с → `public/rewind.mp4`; `viego_v7.mp4` → `public/v7.mp4` (0,43 с лучшего момента).
2. `src/Edit.tsx`: макет (плашка/геймплей/низ), EDL из таблицы, `OffthreadVideo` с `playbackRate` и
   `startFrom`, рампы скорости — отдельными сегментами; счётчик и текст — компоненты с pop-in 6 кадров.
3. Звук: дорожка игры из `game.mp4` по сегментам + `track.wav` с громкостью по таблице.
4. Рендер → `out/viego-penta-meme.mp4`, проверить стопкадры 0, 1,3, 6,9, 8,0, 10,9 с.
Этот макет станет многоразовым шаблоном «хайлайт-мем» (вынести в `video/shared/` для чт/пт).
