# Stylit TikTok — заметки производства

Статус: финал
Создан: 2026-10 (перенесён в студию 2026-10-29)

## Решения
- Формат «пранк в переписке iMessage»: 16 с, 1080×1920, 30 fps (`src/Video.tsx`, персонажи в `src/Figure.tsx`).
- Звуки сообщений (`public/*.wav`) лежат в git как исключение: они маленькие и без них ролик не собрать.

## Как пересобрать
`npm run render -- stylit-tiktok` (из `video/`) → `out/stylit-tiktok.mp4`
