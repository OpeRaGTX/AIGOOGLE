# Виего: бесшовный 3D-луп — заметки производства

Статус: план (режиссура готова; сборка на ноутбуке через Blender MCP)
Создан: 2026-11-04

## Решения
- Один непрерывный шот, без склеек. 16 долей × 0,4295 с = 6,87 с = 412 кадров при 60 fps
  (рендер 30 fps + моушн-блюр → 60 fps дублированием, как в `viego-edit`; при 30 fps — 206 кадров).
- Окружение из `viego-edit`: тёмная пустота, парящие каменные блоки с изумрудным контуром, хейз, изумрудные частицы,
  шлейф по лезвию (`Sword_vfx`). Блоки у траектории камеры — `prune_blocks`.
- **Яркость (урок №1):** тени подняты (gamma 1.28 как в viego-edit), ключевой свет на лице сильнее, чем в прошлых
  шотах; Виего занимает ≥ 45 % высоты кадра большую часть ролика. Тест: кадр 0 и кадр удара в 360 px — читается?

## Бесшовность — технически (обязательно)
- **Поза:** ключи всех костей на кадре 411 копируют кадр 0; idle-цикл подрезать так, чтобы фаза дыхания совпала.
- **Камера:** ключи 411 = 0, кривые со сглаживанием Auto Clamped, тангенсы на концах совпадают (нет рывка скорости).
- **Свет:** все ключи света циклические (значение и наклон на 0 и 411 равны).
- **Хейз и частицы:** не симуляция с началом, а циклический шум: 4D-шум, где W = sin/cos от фазы (кадр/412·2π),
  или кэш длиной 2×, затем кроссфейд последних 0,5 с с началом. Пружины плаща — запечь на 2 цикла, взять второй.
- **Звук:** отрезок 4,97–11,84 с; на стыке кроссфейд 20 мс, чтобы не было щелчка.
- **Проверка:** склеить ролик 3 раза подряд и отсмотреть стыки; разница кадров 411 и 0 — визуально 0.

## Удержание (аналитик)
- 0–0,9 с: глаза в темноте + вспышка → «кто это?» с первого кадра. Риск: слишком темно на превью → глаза и корона
  должны светиться ярко, рим заметный.
- 3,4 с: рывок головы в камеру — ломает плавность, зритель не листает.
- 5,15 с: удар = кульминация; после неё 1,7 с возврата — зритель не успевает уйти, уже начинается второй круг.
- Нет текста и нет концовки → пересмотр выглядит как продолжение. Цель: средний просмотр > 100 % длины.

## Сборка на ноутбуке
1. Скопировать материалы (см. brief.md), открыть Blender с аддоном MCP.
2. Сцена из `viego-edit` → камера и свет по таблице → скриншоты кадров 0, 51, 206, 309, 411 (+ 360 px тест).
3. Анимация на контрол-риге (скилл `character-animator`): блокинг на доли → брейкдауны → сплайн → полировка →
   `bake` → пружины. Playblast → одобрение.
4. Рендер Cycles OptiX 30 fps, моушн-блюр → `work/renders/` → mp4 60 fps; цветокор вшить (`tools/grade.sh`).
5. Remotion: видео + звук-отрезок → `out/viego-loop.mp4`; проверка троекратной склейки.
Оценка: ~2 ч работы + рендер.

## Как пересобрать
`npm run render -- viego-loop` (из `video/`) → `out/viego-loop.mp4`
