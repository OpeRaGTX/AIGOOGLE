## Как снимать (Replay API клиента, https://127.0.0.1:2999, самоподписанный сертификат)
1. Один раз: `Riot Games\League of Legends\Config\game.cfg`, раздел `[General]` → `EnableReplayApi=1`. Открыть повтор.
2. События: `GET /liveclientdata/eventdata` → ChampionKill / Multikill с `EventTime`, `KillerName`; оставить киллы
   пользователя и мультикиллы. Список моментов → `work/moments.json`, показать пользователю.
3. Для каждого момента: `POST /replay/playback` (time = за 4–6 с до драки, speed 1 / 0.5 на килле),
   `POST /replay/render` (интерфейс выкл.: interfaceAll false, fogOfWar по вкусу; cameraAttached на чемпиона
   для «следящих» шотов; FOV), `POST /replay/sequence` — ключи камеры (cameraPosition, cameraRotation, blend)
   для пролётов, `POST /replay/recording` — запись клипа в `work/clips/` (проверить поддерживаемые кодеки/пути).
   Перед записью — скриншот кадра и одобрение.
4. Монтаж в Remotion как в `viego-edit`: трек от пользователя, склейки и слоумо по битам (`tools/beats.py`), 9:16
   кроп с удержанием чемпиона в центре, титр/текст минимально, цветокор `tools/grade.sh`.

## Режиссура пролётов (черновик; уточнить после списка моментов)
- Интро: высокий пролёт над Рифтом к линии/лесу, где первая драка; наезд на чемпиона пользователя.
- Каждый килл: «следящая» камера на чемпионе 1–2 с → на килле облёт 90–180° вокруг точки боя со слоумо 0,5×.
- Мультикилл (если есть): кульминация — низкий ракурс, медленный облёт 360°, слоумо 0,3–0,4× на последнем килле.
- Финал: взрыв нексуса / победа, отъезд камеры вверх; последний кадр под титр.
- 9:16: камера ставится так, чтобы действие было по центру по горизонтали (кроп из 16:9).
