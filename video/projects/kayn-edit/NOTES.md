# Эдит Каина — заметки производства

Статус: финал
Создан: 2026-10 (перенесён в студию 2026-10-29)

## Решения
- 29,4 с, 1080×1920, 60 fps, монтаж под трек 132 BPM (EDL в `src/Edit.tsx`, биты в `src/hits.json`).
- 3D-шоты в Blender (Cycles, OptiX): интро S1, киллы K1–K5, финал-портрет S7. Жертвы реагируют костями
  (`body_reaction` в `pipeline/b3d/action.py`): выгиб спины, голова назад, руки в стороны, ноги подгибаются.
- Цветокор вшит в mp4 (`tools/grade.sh`): шоты 1.12/1.06/1.18, геймплей 1.16/1.06/0.9 (контраст/насыщенность/яркость).

## Материалы (inbox/)
- `предвестник_ночи_каин.glb`, `пантеон.glb`, `ари.glb`, `волибир.glb`, `серафина.glb` — модели (копии с латинскими именами делает build.sh).
- `IMG_7678.MP4` — геймплей; `zandarcb_…mp3` — трек.
- `work/gameplay_60fps.mp4` — геймплей, уже интерполированный до 60 fps (экономит время пересборки).

## Как пересобрать
- `npm run build -- kayn-edit` — недостающие 3D-шоты + монтаж → `out/kayn-edit.mp4`
- `npm run build -- kayn-edit K1_pantheon K3_volibear` — только эти шоты; `--force` — всё; `--no-edit` — без монтажа
- `npm run render -- kayn-edit` — только монтаж. Подробно: `pipeline/README.md`.
