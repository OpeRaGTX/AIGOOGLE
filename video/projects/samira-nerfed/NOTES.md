## Решения
- 27,4 с = затакт + 10 тактов. Такты 1–6: по одному 9999 на сильную долю (подводка 1,4× → удар → слоумо 0,5× одну
  долю → 1×, склейка на 3-й доле). Такт 7: взрыв после даблкилла. Такты 7–8: склейки по долям и разгон 1,5× в дроп.
  Дроп (22,0 с): триплкилл с ультой в слоумо. Последний такт: 807 → 9999 → баннер «ТРИПЛКИЛЛ!», замедление до 0,21×.
- Окно 78 % высоты кадра (562×506 px исходника → 1080×1200), центр на Самире; панорама к цифре 9999, когда она сбоку
  (85 % высоты на двух триплкиллах — там в угол попадают кнопки HUD, иначе 9999 не помещается).
- 720p → предварительный апскейл ×2 (lanczos + unsharp 0,6) в запекании; mci-интерполяция проверена на цифрах урона — чисто.
- Эффекты: зум-панч на каждый удар, вспышка + тряска на хуке и двух триплкиллах, тряска на остальных киллах,
  RGB-сдвиг на склейках, грейд `grade 1.08 1.2 1.02`. Игровой звук выключен.

## Трек (с 0:32, `-ss 32`)
- 88,98 BPM; 16-я сетка: `t = 0.088 + k·0.16854` с (10,11 кадра; уточнено по атакам, ±10 мс), 8-я = 2k, доля = 4k. Такты: `k = 2 + 16n`
  (0,43 · 3,12 · 5,82 · 8,52 · 11,21 · 13,91 · 16,60 · 19,30 · **22,00** · 24,70 · 27,39 с).
- Такты 1–8 (до 21,99 с) — лёгкая часть, с **k = 130 (22,00 с) бас/дроп**. Конец ролика — `k = 162`.

## Движок
- `src/edl.json` — единственный источник правды: сегменты (`at` — шаг сетки k или `{"f": кадр}`, `src` — секунда
  исходника, `speed`; без `src` — продолжение предыдущего = рампа скорости без склейки), ключи кропа `keys`
  (`t` — секунда исходника, `cx`,`cy` — центр 0..1, `h` — высота окна в долях кадра), `fx`: `punch`/`flash`/`shake`/`rgb`.
- `pipeline/prep.py` — запекает `public/gameplay.mp4` (нарезка, скорость, 60 fps: mci-интерполяция там, где после
  изменения скорости < 60 fps, иначе `fps=60`; `"interp": "dup"` в edl или сегменте — дублирование кадров; грейд;
  RGB-сдвиг −2…+6 кадров вокруг меток `rgb`), `public/track.wav` (−14 LUFS, лимитер −1 дБ, фейд 0,3 с) и
  `src/meta.json` (генерируется, руками не править). Сегменты кэшируются в `work/segs/`, пекутся параллельно.
  `until` вместо `speed` — скорость считается так, чтобы к концу сегмента исходник дошёл до этой секунды (удар на бит).
  `upscale`/`sharpen` — апскейл в запекании, `rgbAmp` — сдвиг в запечённых px, `precrop` — область кадра для запекания.
  Интерполяция идёт по реальным таймкодам (VFR), пропущенные кадры записи достраиваются.
- `src/Video.tsx` — окно 1080×1200 (y 360–1560), кроп по ключам со smoothstep, зум-панч 1→1,12, тряска (сдвигом кропа,
  без чёрных краёв), вспышка 3 кадра (0,85/0,45/0,15), лёгкая виньетка, текст «Nerfed? 💀» (Inter 900, обводка + тень,
  центр нижней трети окна, pop-in 6 кадров). Игровой звук выключен.
- `pipeline/sheet.sh [файл] [шаг]` — контакт-листы с таймкодами в `work/sheets/` для поиска киллов.
- Цвет: конверсии явно в bt709, рендер с `--color-space=bt709` (иначе Remotion отдаёт yuvj420p).

## Как пересобрать
`npm run build -- samira-nerfed` (из `video/`): запекание → мастер `work/master.mp4` (crf 15) → `out/samira-nerfed.mp4`
(x264 slow, crf 20, ≤ 8,2 Мбит/с, < 30 МБ). `--no-render` — только запекание, `--force` — без кэша. ~3 мин запекание
(4 ядра) + ~4 мин рендер. Зависимости: ffmpeg, python3 (stdlib); для анализа битов — `pip install librosa`.
