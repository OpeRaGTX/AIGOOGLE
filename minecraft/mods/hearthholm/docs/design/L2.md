# 23. Волна L2: зоны фермера, рыбака и воина

[← DESIGN](../../DESIGN.md) · [Для игрока](../waves/L2.md)

Каркас J2/J3 переиспользован без изменений: `WorkZone` + `ZoneMapService` + `ZoneMapScreen`.
- **Размеры**: `WorkZone.Spec.FARMER (30, 1)`, `FISHER (10, 1)`, `WARRIOR (50, 1)`; регистрация в `WorkSiteTypes.bootstrap` рядом с типом; предпросмотр = `zoneOr(be, ...)` (контур зоны или старая коробка).
- **Модули** (`zone/ZoneModules`): таблица «профессия, тип метки, фабрика работы»; каждая строка регистрирует `ProfessionModule` с зоной MAP и открывалкой `ZoneMapService::open`. Новая профессия с зоной = строка здесь, Spec в bootstrap, использование `be.zone()` в работе.
- **Фермер**: `FarmerJob.zoneGrounds` собирает почву колонок зоны (на уровнях метки -1/-2/0: земля, трава, тропа, грядка) не чаще раза в 100 тиков (до 900 колонок), кэш с хэшем зоны; дальше те же `actionFor`/`Work`. Без зоны: прежний обход радиуса.
- **Рыбак**: `FisherJob.findZoneWater` (public, для теста): колонки зоны, источник воды с воздухом сверху, ближайший к рыбаку; рыбалка и `findStand` как раньше.
- **Воин**: `WarriorJob.next` берёт случайную колонку зоны (`WorkZone.randomColumn`), `defends` проверяет рамку зоны + 4 блока (кроме стойки «сопровождать»).
- **Карта**: общий список опций `ZoneMapScreen.init` теперь рисует и CHOICE (клик по кругу).
- **Модели** (`tools/gen_assets.py` блок «wave L2», текстуры `tools/gen_l2_tex.py`): бочка (ванильные текстуры бочки + `fert_heap`), ведро (`bucket_metal`, `bucket_water`, `fish_body`), камень (текстуры J3 `mine_rock*`, `mine_pick_iron/wood` для меча). Те же id блоков.
- **Тест** `WaveL2Test` (`HH_ONLY_L2=1`): размеры и модули, рыбак выбирает пруд внутри зоны, а не ближний снаружи; фермер вскапывает/сеет только внутри (снаружи 0 грядок); воин ходит внутри зоны и защищает только её; скриншоты трёх меток и трёх карт.
