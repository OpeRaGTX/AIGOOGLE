# 22. Волна L1: боевые роли

[← DESIGN](../../DESIGN.md) · [Для игрока](../waves/L1.md)

Новый пакет `combat/`: каждая заменяемая часть боя в отдельном маленьком классе.
- **`CombatRoles`** (`of(professionId)` возвращает `Role(hpPercent, speedPercent, distressRadius)`): единственное место, где профессия связана с ролью. Числа из `Balance` (читаются при каждом вызове). `SettlerEntity.refreshCombatStats`
  умножает здоровье на `hpPercent`, скорость в `MOVEMENT_SPEED` на корень из `speedPercent` (ускорение моба растёт с квадратом, см. I2), `FOLLOW_RANGE` = max(32, радиус тревоги + 8), чтобы страж находил путь через поселение.
- **`Distress.raise(victim, attacker)`**: вызывается из `SettlerEntity.hurtServer` (через `SettlementService.callGuards`), когда жителя бьёт не игрок. Слышат бойцы в радиусе своей роли, бодрствующие, не в отступлении и свободные.
- **`Shields`**: `holdsShield`, `blocks`, `reduce`; единственный вызов из `hurtServer`. Щит в левой руке любого бойца. Раньше блокировал любой рыцарь без предмета.
- **`Strafe`**: состояние и такт хождения боком/назад (как `RangedBowAttackGoal`), `edgeNear` не даёт шагнуть к обрыву/воде/лаве. Используется `SettlerRangedGoal` в зоне 7..14 блоков.
- **`Promotions`**: таблица `guard→knight (броня)`, `archer→crossbowman`, `warrior→cavalryman`; `SettlementService.promote` общий для всех, цена и уровень в `Balance.PROMOTE_MARKS/LEVEL`; тексты по ключу `gui.hearthholm.promote.<key>`.
- **Профессии** `crossbowman` (инструмент арбалет, работа `CrossbowmanJob extends ArcherJob`; `SettlerEntity.shootsWithHeld`, `Professions.isShooter`) и `cavalryman` (инструмент меч/топор/копьё `ItemTags.SPEARS`, `CavalrymanJob extends WarriorJob`), оба `promotionOnly`. Скины пока берутся у лучника и воина (`SettlerTextures.skinOf`).
- **Арбалет**: `SettlerRangedGoal` с `CROSSBOW_DRAW_TICKS`, скорость стрелы 3,15, `CROSSBOW_EXTRA_DAMAGE_X10`.
- **Кавалерия** (`Cavalry`, `CavalryChargeGoal`, `CavalrymanJob`): в 26.3 лошадью управляет только игрок, поэтому, пока кавалерист сидит на лошади с тегом `hh_cavalry_mount`, `SettlerEntity.getNavigation()` отдаёт навигацию ЛОШАДИ,
  и любая существующая задача (идти, патрулировать, преследовать) ведёт лошадь, не зная о ней. Собственные цели лошади глушит `Cavalry.HeldGoal` (приоритет 0, флаги MOVE/LOOK/JUMP, работает только при теге).
  `CavalryChargeGoal`: фазы CHARGE (скачет на цель, удар копьём с бонусом `CAVALRY_CHARGE_BONUS_X10`) и RUN_PAST (скачет за цель до `CAVALRY_TURN_DISTANCE`), потом разворот. Спешивание: конец смены, сон, отступление, смена профессии (`SettlerEntity.tickMilitary`, `CavalrymanJob.pause`). `SettlerMeleeGoal` не работает верхом.
- **Воин без метки** патрулирует радиус поселения (`WarriorJob`), `Settlement.radius()`.
- **Тест** `WaveL1Test` (`HH_ONLY_L1=1`): соотношения здоровья и скорости, щит (чистая функция и настоящий удар), тревога за 50 блоков (отвечает только страж, воин и лучник молчат), стрейф лучника (смещение, дистанция, попадания, жив), повышения за 25 марок (арбалетчик стреляет), кавалерист: седло из карманов, посадка, ≥2 тарана, ≥1 разворот, убит враг, слезает после смены. Тест D: рыцарь теперь из стража за 25 марок.
