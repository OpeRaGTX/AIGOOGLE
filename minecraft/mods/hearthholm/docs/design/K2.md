# 18. Волна K2: рабочий день, сдача вещей, темп шахтёра

[← DESIGN](../../DESIGN.md) · [Для игрока](../waves/K2.md)

- **Рабочий день** (`Balance.inWorkday`, `SettlerEntity.workAt`): ветка «по умолчанию» для профессий без `nightShift()` теперь
  `floorMod(t - WORKDAY_START_TICK, 24000) < 12000 * WORKDAY_DAYLIGHT_PERCENT / 100` (0..9000). Явные смены стражи (`SHIFT_DAY/NIGHT/ALWAYS`) и ночная
  смена профессий с `nightShift()` не тронуты; сон (`sleepAt`) всегда старше работы. Окно между концом работы и сном остаётся досугом:
  `IdleActivity` («вечер»), `ChatActivity`, `TavernActivity` (`Tavern.canVisit` = не сон и не работа).
- **Сдача в конце смены**: `Job.endOfShift` (по умолчанию `null`), реализация в `BaseJob`: `hasUnloadable` / `unloadInto` / `keptGear`.
  Остаются: инструмент профессии, `SettlerMenu.isToolOrWeapon`, броня (`SettlerMenu.armorSlot`), щит, стрелы лучника и `SHIFT_END_KEEP_FOOD`
  единиц еды (стопка делится). Место: `findSpace(dropOffs())`, у `SiteJob` это сундуки рядом с меткой (`chestsNear`), потом склад.
- **`ShiftEndActivity`** (в `SettlerBrain` перед `SleepActivity`, после тревоги и отряда): ждёт `SettlerEntity.shiftUnloadDue()`
  (`lastWorkTick > lastUnloadTick`, смена кончилась, не спит, не безработный). `WorkActivity` каждый тик зовёт `markWorked()`, активность по завершении
  `markUnloaded()`. До `MAX_TRIPS` = 4 рейсов подряд (полный сундук = следующий контейнер). Поля не сохраняются: после перезагрузки цикл
  начнётся со следующей рабочей смены.
- **Дровосек**: `LumberjackJob.wanted` снова принимает любой непустой предмет (откат фильтра J1); прежняя разгрузка при полных карманах осталась.
- **Шахтёр**: `SettlerEntity.minerSlowdown()` множит `breakTicks` на `MINER_SLOW_PERCENT_AT_LEVEL1 / 100` на уровне 1, линейно до 1 на
  `MINER_FULL_PACE_LEVEL`; только для профессии шахтёра (`BreakBlock` использует и строитель при расчистке).
- Тест `WaveK2Test` (`HH_ONLY_K2=1`): расписание (работа, досуг, сон; стража без изменений), никто из гражданских не работает вечером,
  сдача в сундук у метки и на склад, «один раз за вечер», точный темп шахтёра против старой формулы (`MINER_SLOW_PERCENT_AT_LEVEL1 = 100`).
