# 12. Волна I1: играбельность работников

[← DESIGN](../../DESIGN.md) · [Для игрока](../waves/I1.md)

- Баланс (все числа в `core/Balance`, можно править в `config/hearthholm.json`): `BUILD_DELAY_TICKS` (26) и `BUILD_SKILL_PERCENT_PER_LEVEL` (8) — темп строителя; `MINE_TORCH_EVERY_SPIRAL` (6) / `MINE_TORCH_EVERY_TUNNEL` (8), `MINE_VEIN_CAP` (32); `BREAK_PACE_PERCENT` (150) и `BREAK_SKILL_PERCENT_PER_LEVEL` (4) — время ломания = ваниль (твёрдость x30/скорость инструмента, x100 если инструмент не подходит) x pace; `LEVEL_XP` {0,100,300,600,950}, `XP_WORK_TICKS` (110), `XP_ACTION_PERCENT` (10).
- Опыт: `WorkActivity` вызывает `SettlerEntity.workTick()` в каждый тик активной (не `Wait`) задачи, 1 очко за `XP_WORK_TICKS`; `gainXp(n)` из работ даёт только `XP_ACTION_PERCENT` процентов.
- Материалы чертежа: `Blueprint.accepts/sameKind/variant` — группы по тегам (кровати, ковры, шерсть: любой цвет; доски, ступени, плиты, брёвна, заборы, двери: сначала точный предмет, затем любая порода); `PlaceBlock` получает вариант блока с теми же свойствами (направление, половина, форма). `Blueprint.materialList()` — строки «любая кровать/ковёр/шерсть» для экрана колышка. Начало чертежа сдвинуто на 2 блока от колышка (`toWorld`: z+2).
- Шахта: `MinePlanner` строит двойные полосы (туннель, шахта, спираль с внешней полосой), факелы на столбе спирали каждые N шагов; `MinerJob` ставит жилу в очередь (заливка 26 соседей, `isOre`), берёт факелы со склада.
- Инструмент: `BaseJob.toolTrip()` берёт инструмент из карманов, затем из сундука у метки и со склада (лучший по материалу и прочности); `requiresTool()` у шахтёра и лесоруба, мотыга у фермера нужна только для вспашки; без инструмента `complainNoTool()` (статус, мысль «нет инструмента», пузырь `need_pickaxe/axe/hoe`).
- `ResidentRecord` хранит `hp/maxhp` (по умолчанию 20), `Views.Resident/Settler` передают здоровье.
